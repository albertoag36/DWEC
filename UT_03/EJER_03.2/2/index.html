• ¿Qué es HTML?

    HTML es el lenguaje de marcado que define la estructura de una página web.

  • ¿Para qué sirve CSS?

    CSS se usa para dar estilo y diseño a los elementos de una página web.

  • ¿Qué hace JavaScript?

    JavaScript añade interactividad y comportamiento dinámico a la página.

  • ¿Qué es el DOM?

    El DOM es la representación en forma de árbol del documento HTML que JavaScript puede leer y modificar.
